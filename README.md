# 사목 AI 대전

세로줄에 돌을 떨어뜨려 가로·세로·대각선으로 **4개를 먼저 잇는** 게임을, **몇 수 앞을 내다보는 AI**와 겨룹니다. AI가 살펴본 경우의 수와 각 줄에 매긴 점수가 그대로 보여, 게임 트리 탐색(미니맥스·알파-베타 가지치기·평가 함수)의 원리를 자연스럽게 체험할 수 있습니다. 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

> **바로 하기: https://woojuntaek-lgtm.github.io/samok-ai/**

## 특징
- AI 4단계: 초급(2수 앞, 가끔 실수) · 중급(4수) · 고급(6수) · 고수(8수, 수십만 가지 탐색)
- 선공 선택, 무르기, 단계별 전적 저장, **💡 훈수**(같은 AI가 내 입장에서 6수 앞까지 계산해 최선의 줄을 알려 줌)
- AI가 둘 때마다 "몇 수 앞까지 몇 가지를 몇 ms 동안 살펴봤는지"와 7개 줄별 점수 표시
- 쉬운 말로 쓴 AI 원리 설명(게임 트리, 미니맥스, 알파-베타, 휴리스틱, 알파고와의 연결)
